# MiniProject_1_Muhammad-Khaidir-Ali-Ramadhani
NIM : 2609116015

TEMA : Sistem Pengelolaan Data Tiket Festival.

Penjelasan Program :
Program ini dibuat untuk mengelola data tiket dalam suatu festival dengan sederhana menggunakan Phyton. Kita dapat menambah, melihat, mengubah, dan menghapus data.

Fitur Program :
-Tambah Data.
-Tampilkan Data.
-Ubah Data.
-Hapus Data.
-Keluar.

Kode Program yang dipakai : 
-Input dan Output = Memasukkan dan menampilkan data.
-Variabel = Menyimpan data.
-List dan Tuple = Menyimpan kumpulan data.
-If dan Else = Percabangan.
-While Loop = Pengulangan proses.
-CRUD = Proses tambah, tampilkann, ubah, dan hapus data.
